# SKY QUEST ADVENTURE 3D

A browser-based 3D platform adventure built with Kenney assets.

## Run / publish
- Keep `index.html` at the repository root.
- Keep the complete `assets` folder beside it.
- Publish the repository root with GitHub Pages (`main` branch, `/ (root)`).
- The game loads Three.js from jsDelivr, so an internet connection is required.

## Controls
- WASD / Arrow keys: move
- Space: jump (double jump)
- Shift: dash
- Mouse drag: orbit camera
- Escape / top-right button: pause
- Touch controls appear on touch devices

## Included content
- Kenney Platformer Kit GLB models
- Kenney Car Kit GLB models
- Kenney Train Kit GLB models
- Kenney Watercraft Pack GLB models
- Kenney Animated Characters Protagonists FBX model, skins and animation clips

## Notes
The game is tuned for lightweight rendering: no real-time shadows and capped pixel ratio.
The protagonist FBX and animation clips are loaded as optional character animation; if a browser cannot load FBX, a Kenney GLB character remains as fallback.

Please keep the accompanying Kenney license files with the project.
